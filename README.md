# TP TypeScript — Académie des sorciers

## Installation
1. Installer Node.js.
2. Dans le dossier du projet, lancer `npm install`.
3. Lancer le TP avec `npm start`.
4. Pour vérifier la compilation : `npm run build`.

Le projet reprend les six exercices du document : ajout et recherche des sorciers, type `Extract`, validation par décorateur, cache de méthode et Type Guards.
